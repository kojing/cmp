# ランダム配置の街 (以前の city-random-textures の意匠) ― タイル方式のテクスチャ

以前の「ランダム配置 (ミラー)」の街を、今のタイル方式 (ポリゴン 1 枚 = タイル 1 枚、マージン付き、繰り返し) に合わせて作り直したものです。
敷地に沿った建物、曲がった道路と高架、駐車場・砂利の空き地などの見た目は元のままです。

- 元の 2048 × 2048 はミラーで繰り返す前提なので、元 / 左右反転 / 上下反転 / 両方 を並べた 4096 × 4096 を
  **そのまま繰り返してつながるマップ** にし、コア 2048 の 4 タイルに分けています
  (`0_0` = 元、`1_0` = 左右反転、`0_1` = 上下反転、`1_1` = 両方。画像の左上が 0_0)
- 大きさ:2432 × 2432 = コア 2048 + 片側マージン 192 (cone だけ 1216 × 1216)
- 輪郭をなめらかにするため、配置は元の 2 倍 (4096) で作り、アンチエイリアスつきのマスクにしてから 2048 に戻しています。
  配置は画素で作った形なので、領域 (建物・高架・柱) ごとに符号付き距離を少しぼかして縁の階段を消してから、
  mask (2048、アンチエイリアス 256 段階) と top / bottom (4 倍の 8192) を作り、city_bake.py の `--mirror` で 2048 のまま焼いて鏡に映して並べています
- 高さは 4 の倍数 (元の 135 / 143 / 159 / 175 / 191 は +1)

| ファイル | サンプラー | 中身 |
|---|---|---|
| `tile*_data.png` | `uCityData` | R 下端 / G 上端 / B 境界までの距離 |
| `tile*_roof.png` | `uCityRoof` | 屋根の色 |
| `tile*_ground.png` | `uCityGround` | 地面の色 (建物の中は壁の色) |
| `tile*_cone.png` | `uCityCone` | 円錐ステップ値 (1 チャンネル) |
| `tile*_outline.png` | `uCityOutline` | 一番近い境界までの距離 (1 チャンネル。外側の輪郭と段の境目) |
| `map/map_*.png` | — | タイルに分けていない 4096 × 4096 |

シェーダーの値:`TEX_CORE = 2048`、`TEX_SIZE = 2432`、`DIST_SCALE = 2`、`CONE_MAP_W = 4096`、
`HEIGHT_SCALE = 0.125` (元と同じ高さ)。デモは `demo/city_polytile_random.html` (1 枚 2000 × 2000 のポリゴン、ズーム 1 で 1 テクセル ≒ 1 ピクセル)。
作り直す時は `dev/random_city/` の 3 つのスクリプトを順に実行します。
